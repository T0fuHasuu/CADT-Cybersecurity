💀 Demo — Missing Authorization

The "From Account" dropdown only shows your accounts in the UI, but the server accepts any account ID in the POST body.

Step 1: Open DevTools → Inspector → change the dropdown option to ACC004

Step 2: Set amount to 10000, pick your account as destination, and click Send.

Step 3: Watch $10,000 move from admin's account to yours!

Or use curl to bypass the form entirely:
curl -X POST http://localhost:5000/transfer \
  -b "session=YOUR_SESSION" \
  -d "from_account=ACC004&to_account=ACC001&amount=10000"

✅ Secure Fix

After parsing from_account, the server must verify: 

if from_account["user_id"] != session["user_id"]:
    abort(403)  # Forbidden

Server-side ownership checks can never be bypassed by client manipulation.
